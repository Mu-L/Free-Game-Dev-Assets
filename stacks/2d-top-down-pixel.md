# Make a 2D top-down pixel game

For a solo developer making an overhead pixel game in any engine. The world art is 16x16 and drawn in 3/4 view: the ground seen from above, buildings and characters shown from the front. See Gaps for a straight-down view.

## Art

- **Characters, monsters and a starter world:** [Ninja Adventure](../catalog/2d/ninja-adventure.md). One 16x16 pack with 50+ characters, 30+ monsters, bosses, tiles, UI, effects, 100+ sound effects and 37 music tracks; characters face four directions.
- **Town tiles:** [Kenney Tiny Town](../catalog/2d/kenney-tiny-town.md). 130 tiles for an overworld town: houses, roofs, fences, trees, paths and a few villagers.
- **Dungeon tiles:** [Kenney Tiny Dungeon](../catalog/2d/kenney-tiny-dungeon.md). 130 dungeon and sewer tiles: floors, walls and props, also 16x16.
- **Controller prompts:** [Kenney Input Prompts](../catalog/2d/kenney-input-prompts.md). 1500+ button glyphs at 64x64 plus vectors, covering Xbox, PlayStation, Switch, Steam Deck, keyboard, mouse and touch.
- **Menus and HUD:** [Kenney UI Pack](../catalog/2d/kenney-ui-pack.md). 430 buttons, panels and sliders.

## Audio

- **Music:** [Abstraction Music Loop Bundle](../catalog/audio/tallbeard-abstraction-music-loop-bundle.md). 200+ loops, for more music than the 37 tracks in Ninja Adventure.
- **Menu sounds:** [Kenney Interface Sounds](../catalog/audio/kenney-interface-sounds.md). 100 interface and button clicks for dense menus and HUD feedback.

## Fonts

- **Terminal-style text:** [VT323](../catalog/fonts/vt323.md). A CRT terminal-style monospace for debug overlays, hacking UIs and HUD text.

## Tools

- **Map editor:** [Tiled Map Editor](../catalog/tools/tiled.md). A tilemap editor for ortho, isometric and hex maps. Read the entry before shipping any of Tiled's own code inside your game.

## Gaps

- No straight-down character set that turns in four directions. The two four-direction sets in the catalog, Ninja Adventure and the [ArMM1998 Zelda-like set](../catalog/2d/armm1998-zelda-like.md), are both 3/4 view (ledger, 2026-09-23).
